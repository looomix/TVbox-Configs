接口源库 · 一键接入

接入即进入云端抓取队列：自动去重、逐条验证，未通过验证的接口不会写进订阅配置；每 7 天随更新一起刷新。

新增视频源

保存会直接提交到仓库的 sources/sources.json，并在后台触发一次检测；令牌只留在本机浏览器。

GitHub 访问令牌

建议使用 fine-grained token，只授权本仓库的 Contents: Read and write 与 Actions: Read and write 权限。令牌只写入浏览器本地存储，不会上传到别处。
