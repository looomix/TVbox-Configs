05

自己部署

Fork 仓库后开启 Actions 与 Pages，即可拥有自己的订阅服务。

Fork → Actions → Pages
  1. Fork 本仓库，在 Actions 页启用工作流。
  2. Settings → Pages：Source 选 Deploy from a branch，Branch 选 main、/ (root)。
  3. 仓库设为 Public；在管理页「设置令牌」填入仅授权本仓库 Contents、Actions 读写的 fine-grained token。
  4. 等待 Update Configs 完成，订阅链接中的用户名会自动跟随你的仓库。
GitHub 仓库 · 本项目只生成配置文本，不承载、不代理任何第三方内容；接口与内容版权归原站点所有。
